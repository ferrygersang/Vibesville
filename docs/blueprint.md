# **App Name**: Vibesville

## Core Features:

- Mood Selection: Users can select their current mood from a dropdown or using emoji buttons (Sad, Stressed, Happy, Tired).
- AI Quote Generation: Generates a motivational or funny quote based on the selected mood using generative AI; the AI tool decides whether to include the name of an imaginary expert to support its claims, or make some claims seem funny or lighthearted..
- Quote Display: Displays the generated quote on a prominent card with visually pleasing typography.
- Save Mood: Ability to save user moods to the local storage for trend analysis. Display moods as trend. 

## Style Guidelines:

- Primary color: Soft Lavender (#E6E6FA) to promote calmness.
- Background color: Light gray (#F0F0F0) - almost white, for a clean interface.
- Accent color: Pale blue (#B0E2FF) for interactive elements and highlights, for a lighter tone.
- Headline font: 'Belleza', sans-serif for an elegant and inviting feel. Body text: 'Alegreya' for readability.
- Use simple, rounded icons representing different moods.
- Clean and centered layout for easy readability. Quote card is prominent and visually appealing.
- Gentle fade-in animations for quotes and mood changes to make the user experience fun and exciting.
